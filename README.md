# Twin Stars (Blue Lock inspired)

A single-file 3D story football game for the browser. Play as Nagi Seishiro, avenge Isagi, and take on Aoba United and the Hokuto Prototypes.

Open `index.html` in a modern browser (desktop or phone) to play. Everything (models, voice clips, music) is embedded in that one file.

Play online: https://dhruvjoshi007.github.io/Blue-Lock/ (after GitHub Pages is enabled)
